# Disney Mayhem — Codex Rules

You are building Disney Mayhem, a private family trip dashboard for a Disney World vacation.

Do not overbuild. Prioritize clarity, speed, mobile usability, and reliability.

## Product goal

Disney Mayhem should answer one question at any moment:

"What do we need to know right now?"

## Build approach

- React + TypeScript + Vite
- Static site (GitHub Pages)
- Local data files
- localStorage for edits
- No backend
- Mobile-first

## Naming

The app name is Disney Mayhem.
